# 🧮 Tabuada das 4 Operações com Funções

Este projeto é uma **tabuada interativa desenvolvida em Python**, criada para praticar o uso de **funções** e lógica de programação.  
Ele permite gerar a tabuada de **adição, subtração, multiplicação e divisão** de qualquer número, através de um **menu interativo** no terminal.

## 🚀 Funcionalidades
- Gerar tabuada de **adição**  
- Gerar tabuada de **subtração**  
- Gerar tabuada de **multiplicação**  
- Gerar tabuada de **divisão**  
- Menu interativo para seleção da operação  
- Permite repetir quantas vezes o usuário desejar  

## 🧠 Conceitos aplicados
- Criação e uso de **funções** em Python  
- Estruturas condicionais (`if`, `else`)  
- Estrutura de repetição (`while True`)  
- Entrada e saída de dados no terminal  

## 💻 Como executar
1. Certifique-se de ter o **Python 3** instalado no computador.  
2. Baixe o arquivo `tabuada.py`.  
3. No terminal, vá até a pasta onde o arquivo foi salvo e execute:
   ```bash
   python tabuada.py
